Deterministic Parametric Settlements
Standard oracle models suffer from variable network latency and parsing mismatches. PERIL operates on GenLayer's deterministic intelligent consensus—allowing validators to converge absolutely on status-page endpoints.
End-to-End Parametric Lifecycle
Buy Policy

Incident Query
[02]

Calculate Duration
[03]

[04]

[05]
Locked capital is disbursed to claimant wallet. Payout is permanently Finalized (~3m) in block archives.
Downtime API Field Anatomy
Deterministic evaluation requires extracting specific metadata. GenLayer smart contracts parse status page JSON endpoints targeting these standardized keys:
{
  "id": "zkxwbgr0cnmx",
  "name": "Database Outage on Actions API",
  "created_at": "2026-09-17T04:12:00Z",
  "resolved_at": "2026-09-17T11:47:00Z",
  "impact": "major",
  "status": "resolved"
}
• id: Prevents double-settlement claims.
• created_at / resolved_at: Subtracting resolves absolute duration.
• impact: Must parse as "major" or "critical" to reject benign slips.
